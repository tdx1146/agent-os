## 环境需求

| 项目 | 说明 |
|------|------|
| 操作系统 | Linux（FNOS NAS 已验证） |
| Python | 3.11+ |
| Node.js | v22+ |
| OpenClaw | v2026.3.13+ |
| Gateway 端口 | 22881（默认） |
| Gateway Token | 需配置（环境变量或 openclaw.json） |
| 会话目录 | agents/main/sessions/ |
| 编辑器端口 | 18888 |
| BROWSE_ROOT | 环境变量，文件管理器根目录（默认：所有自动化/） |

## 部署步骤

```
1. cp 所有自动化/找回自己/* → <workspace>/
2. cp edit-web.py + inject-helper.mjs + pulse.sh → 任意目录
3. 配置 GATEWAY_PORT + GATEWAY_TOKEN + BROWSE_ROOT 环境变量
4. python3 edit-web.py → 启动编辑器（端口 18888）
5. 设 cron: 0 * * * * <path>/pulse.sh
6. 第一个 session 自动创建
```

## 启动后验证

- 编辑器页面右上角显示「🌫️ 你找到我了」→ 摸摸协议就绪
- 工具栏点击 📂 文件管理 → 文件树展开 → 根目录为 BROWSE_ROOT
- 点 🔍 索引 → 搜索历史备份中的用户消息
- 点 📋 索引报告 → 确认所有组件正常
