## A. 触发通道（工程可行性）

**发现**
1. **轻如烟 inject 已跑通全链路**：inject-helper.mjs = 裸 WebSocket 连 Gateway（端口 22881，token 认证，client id `openclaw-control-ui`），发 `chat.send` RPC；edit-web.py 包 HTTP `/api/momo` → inject_via_websocket()，带注入锁（每用户轮 1 次+TTL，防自我递归 token 耗尽）。守夜/自问/踱步脚本已生产验证。
2. **OpenClaw 官方第一类外部唤醒接口**：`POST /hooks/wake`（main session 入队系统事件，mode: now|next-heartbeat，字段 text）与 `POST /hooks/agent`（isolated 回合），需 hooks.enabled + token。`chat.inject` 仅写 transcript 不触发 run（不适合）。cron `--wake` 需预建 job（绕）。

**建议**
- 方案1（推荐）：LMS 侧直接 `POST /hooks/wake`——几乎零新代码，事件进 main 系统事件流。
- 方案2（fallback）：复用 inject-helper.mjs chat.send（可指定任意 session、已生产验证，但绕过 hooks 安全边界）。
- 方案3：轮询总线 + cron run（有延迟，不推荐）。

## B. Salience 判据（科学依据）

- **选择性唤醒是大脑默认架构**：Salience Network（Seeley 2007, pubmed 17329432）。
- **显著性 = 概率更新量**：surprise = KL 散度，可解析计算（Baldi & Itti 2010, pubmed 20080025）——LMS entropy/surprise 有直接数学依据。
- **预测误差是通用唤醒信号**：预测编码只传残差（Rao & Ballard 1999）；自由能 = 最小化 surprise（Friston 2010）；多巴胺 = 奖励预测误差（Schultz 1997）。
- **记忆 gate 三路合流**：novelty + salience + goal 共同决定（Lisman & Grace 2005）——判据应三路并查。
- **工程先例**：Generative Agents importance score（2304.03442）；MemGPT memory pressure（2310.08560）；Proactive Agent 学"该不该主动"（2410.12361）。

**判据建议**：① surprise/KL（主信号）② entropy 漂移 ③ purpose_coherence 跌落 ④ 事件类型权重 ⑤ 重要度评分。
阈值：双阈值+连续计数+边沿触发（复用 self_pulse v2：entropy>0.9 连 3 次、purpose<0.8 连 3 次）；surprise 用相对基线 z-score（均值+2σ）。合流规则：novelty×salience×goal 加权，合流才打断。

## C. 体力极限系统（防自激循环）

**科学依据**：Borbély 两过程模型（Process S 睡眠压力饱和指数上升×快指数衰减，1982/2016, pubmed 26762182）；腺苷是介质（Porkka-Heiskanen 1997 Science）。

**本地可复用**：注入锁（每轮 1 次+TTL）= 初代体力限制原型；self_pulse v2 边沿触发+输出分级（噪音治理骨架）；pacing.sh 是无上限自注入的反面教材。旧代码无完整体力系统，需新设计。

**参数化建议**：
- 唤醒压力 W(t)：每次自主活动 W += ΔW_act；清醒期 τ_wake≈30-60min 缓慢衰减。
- 紧急 override：W 高时 anomaly/告警可强唤醒（人类被地震吵醒），但记入成本。
- 休眠：W > θ_sleep(≈0.7) → 强制休眠期（停自主唤醒，仅保留硬告警）；时长 ∝ 超出量。
- 恢复：τ_sleep≈15-30min 指数衰减，降至 θ_awake(≈0.2) 恢复。
- 防自激三件套：冷却期（注入锁 TTL 思路）+ 同事件去重游标 + 输出分级（无实质动作不触发再唤醒）。
