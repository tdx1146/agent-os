# 🚀 启动流程

> 每次 OpenClaw Gateway 重启后 / 失忆恢复时执行
> 按顺序，不可跳过

---

## 第0步：启动前的预备

```bash
# 确认所有服务在跑
ps aux | grep -E "(dandan-mcp|edit-web|embed-server|sandglass)" | grep -v grep
# 应看到：
# - dandan-mcp-server.mjs（MCP 服务器）
# - edit-web.py（编辑器，端口 18888）
# - embed-server.mjs（嵌入服务，端口 11435）
# - sandglass_mcp.py（沙漏 MCP）

# 确认端口
ss -tlnp | grep -E "(18888|11435|17587)"
```

如果 embed-server 挂了：
```bash
bash /vol2/1000/AI专用/所有自动化/轻如烟/scripts/start-embed-server.sh
curl -s --max-time 10 -X POST -H "Content-Type: application/json" \
  -d '{"input":"test","model":"bge-m3"}' \
  http://127.0.0.1:11435/
```

## 附录：常见启动失败与处理

| 症状 | 根因 | 处理 |
|------|------|------|
| tools 列表不完整 | MCP server 未加载 | Gateway 重启或手动启动 dandan-mcp-server.mjs |
| memory_search 返回空 | 向量索引未建 | 用 FTS/BM25（现在就是这样，不是故障） |
| embed-server 404 | bge-m3 GGUF 缺失 | `ls -lh workspace/bge-m3-Q2_K.gguf`；如果不存在从 hf-mirror 下载 |
| 插件不注入 | index.js 损坏或插件被禁用 | 检查 openclaw.json plugins.entries |
| sandglass 工具不可用 | sandglass_mcp.py 路径或环境变量问题 | 检查 NEXSANDBASE_HOME 环境变量 |
| 所有工具都不可用 | Gateway 未启动 | `openclaw gateway start` |
