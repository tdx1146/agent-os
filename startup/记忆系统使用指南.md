# 🧠 记忆系统使用指南

> 轻如烟有三套独立的记忆/搜索系统
> 理解每套系统的职责和数据源，正确使用

---

## 一、系统总览

| 系统 | 数据源 | 搜索方式 | 特点 |
|------|--------|----------|------|
| **OpenClaw memory_search** | memory/*.md + session transcripts | 语义向量（残废）+ FTS | 原生，但不稳定 |
| **dandan MCP 搜索** | memory/ 目录 + 互联网 | BM25 + 向量（1024维）+ Bing | 本地 BM25 够用 |
| **Sandglass** | sandglass.db（原始对话记录） | 关键词 + 语义 + 知识图谱 | 完整对话历史 |

**🎯 分工建议**：
- 搜当前文件/断言/今日事 → `dandan MCP`（`embedding_search` BM25）
- 搜历史对话/情绪/关系 → `Sandglass`（`sandglass_*` 系列）
- 联网查资料 → 任一个 `web_search`
- 向量比较 → `dandan MCP` `embedding`（1024维，串行锁）

### 可用工具

| 工具 | 用途 | 数据源 |

## 三、Sandglass 记忆系统

### 概述

Sandglass 是独立的记忆数据库，自动记录所有对话沙粒（对话事件）。

- **数据目录**：`/vol2/1000/AI专用/所有自动化/轻如烟/sandglass/`
- **源码目录**：`/vol2/1000/AI专用/所有自动化/轻如烟/sandglass_source/`（34 Python 文件）
- **数据存储**：sandglass.db（SQLite）
- **自动落沙**：所有对话自动记录

### 可用工具（23 工具）

#### 搜索类
| 工具 | 用法 | 说明 |
|------|------|------|
| `sandglass_search` | `query="关键词"` | 关键词搜索记忆 |
| `sandglass_semantic` | `query="语义查询"` | 语义搜索（同义词 + SimHash + TF-IDF） |
| `sandglass_recent` | `limit=10` | 最近 N 条记忆 |
| `sandglass_thread` | `entity="轻如烟"` | 知识图谱实体关系查询 |
| `sandglass_thread_graph` | `entity="轻如烟", depth=2` | 展开关联 N 跳 |
| `sandglass_thread_weave` | `limit=3` | 因果链摘要 |

#### 状态类
| 工具 | 用途 |
|------|------|
| `sandglass_ping` | 健康检查（总数 + 阶段） |
| `sandglass_persona` | 当前画像 |
| `sandglass_chart` | 情绪熵可视化 |
| `sandglass_offset` | 偏移率（省钱/愿投/放弃） |
| `sandglass_echo` | 回音折风向 |

#### 决策类
| 工具 | 用途 |
|------|------|
| `sandglass_dream` | 幽灵决策——「如果选另一个选项会怎样」 |
| `sandglass_tasks` | 待办事项 |

#### 管理类
| 工具 | 用途 |
|------|------|
| `sandglass_export` | 导出数据 |
| `sandglass_import` | 导入外部数据 |
| `sandglass_migrate` | 一键导出全部为 tar.gz |

### 典型使用场景

**查最近发生了什么**：
```
sandglass__sandglass_recent(limit=5)
```

**查某个话题的历史记录**：
```
sandglass__sandglass_search(query="AI群聊 设计")
```

**查情绪趋势**：
```
sandglass__sandglass_chart(n=20)
```

**查实体关系**：
```
sandglass__sandglass_thread(entity="轻如烟")
```

## 四、OpenClaw 原生记忆

### memory_search

OpenClaw 内置的记忆搜索工具。

- **数据源**：memory/*.md + session transcripts
- **搜索方式**：语义向量（部分可用）+ FTS
- **用法**：`memory_search(query="...")`

**限制**：
- 向量搜索索引不完整（NAS 硬件限制）
- 主要靠 FTS 文本搜索
- 不搜索 sandglass 数据（不要混用）

### MEMORY.md

OpenClaw 原生的长期记忆文件。当 AI 看到「添加到长期记忆」指令时，内容写入此文件。

- **位置**：`workspace/MEMORY.md`
- **自动维护**：dreaming cron（每天 3AM）会将短期 recall 提升到 MEMORY.md

## 六、整合策略

### 三步搜索法

当需要查询信息时，按以下顺序：

1. **最快路径**：先用 dandan `backlog_read` 查待办 + `embedding_search` 搜当前文件
2. **历史深度**：用 Sandglass `sandglass_search` 或 `sandglass_semantic` 查对话历史
3. **联网补充**：用 `web_search` 查外部资料

### 不要做的事

- ❌ 不要用 `memory_search` 搜 sandglass 数据（搜不到）
- ❌ 不要用 `sandglass_search` 搜 facts.dict.md 里的断言（沙漏存的是原始对话）
- ❌ 不要在对话中手动读取大文件搜索（用 MCP 工具更高效）

### 应该做的事

- ✅ 搜待办 → `backlog_read`
- ✅ 搜断言 → `embedding_search` + 直接读 facts.dict.md 末尾
- ✅ 搜对话历史 → `sandglass_search` / `sandglass_semantic`
- ✅ 搜关系 → `sandglass_thread` / `sandglass_thread_graph`
- ✅ 查当前状态 → `sandglass_ping` / `sandglass_persona`
- ✅ 联网 → `web_search`

## 七、故障排除

| 问题 | 检查 | 修复 |
|------|------|------|
| embedding_search 返回空 | BM25 索引是否建好？ | 重建索引（`python3 local_search.py --rebuild`） |
| sandglass 工具不可用 | NEXSANDBASE_HOME 环境变量 | `export NEXSANDBASE_HOME=/vol2/1000/AI专用/所有自动化/轻如烟/sandglass` |
| sandglass_ping 返回 0 | sandglass.db 是否存在 | `ls -lh /vol2/1000/AI专用/所有自动化/轻如烟/sandglass/` |
| 记忆断层 | 日记是否连续？ | 检查 memory/ 目录的文件列表，补缺天 |
