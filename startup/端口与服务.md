## 启动命令参考

```bash
# Gateway 启动（由 systemd 管理）
# openclaw 进程由 /vol1/@appcenter/trim.openclaw/server/index.js 通过 bun 执行
# process name: openclaw

# edit-web 启动
python3 /vol2/1000/AI专用/所有自动化/轻如烟/scripts/edit-web.py &

# dandan MCP 服务器
node /vol1/@apphome/trim.openclaw/data/workspace/dandan-mcp-server.mjs &

# sandglass MCP
python3 /vol2/1000/AI专用/所有自动化/轻如烟/sandglass_source/sandglass_mcp.py &

# 插件热重启（仅 SIGUSR1）
# kill -USR1 <openclaw-pid>
# 禁止连击，确认 session 空闲后再发
```
