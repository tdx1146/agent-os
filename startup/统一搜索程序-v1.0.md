# 🌫️ 统一搜索程序 v1.0

> 确保「先沙漏、后向量、再文件」三步搜索，最大化信息召回率

---

## 一、搜索铁律

**优先准确，兼顾速度。毫秒 vs 1秒无实际意义。**

**三步搜索顺序**：
1. **沙漏搜索** — 快速定位时间点 + 用户原话
2. **向量搜索** — 深度扩展相关文档 + 专门分析
3. **文件读取** — 确认当前状态 + 活断言

---

## 二、标准搜索程序

### Step 1: 沙漏搜索（定位时间点）

**目的**：找到用户说这件事的**时间**和**原话**

```python
# 调用
sandglass__sandglass_search(
    query="关键词", 
    limit=20  # 多拿几条，避免遗漏
)

# 分析结果
- 提取时间戳（ts）
- 提取用户原话（text）
- 记录最早时间 + 最近时间
```

**输出**：
- 最早时间：`2026-XX-XX`
- 最近时间：`2026-XX-XX`
- 用户原话：`"..."`

---

### Step 2: 向量搜索（扩展细节）

**目的**：找到所有相关文档、分析报告、专门文档

**关键：利用沙漏结果优化向量搜索关键词**

```python
# 根据沙漏结果优化关键词
if 沙漏找到时间:
    向量关键词 = 原关键词 + 时间段 + 相关词

# 调用
dandan__vector_search(
    query=优化后的关键词,
    maxResults=20  # 多拿几条
)

# 分析结果
- 找到专门文档（xxx-safe-rules.md、xxx-root-cause.md）
- 找到完整分析（2026-XX-XX.md）
- 找到 SKILL 文档
```

**输出**：
- 专门文档：`xxx-safe-rules.md`
- 完整分析：`2026-XX-XX.md`
- SKILL：`skills/xxx/SKILL.md`

---

### Step 3: 文件读取（确认状态）

**目的**：确认当前配置状态、活断言

```python
# 读取关键文件
- facts.dict.md（活断言）
- 最新的轮感文件
- 专门文档
```

**输出**：
- 当前状态：`✅ 已修复 / ❌ 待修复`
- 活断言：`铁律内容`

## 三、关键词优化规则

### 规则 1：时间词增强

**沙漏找到时间 → 向量搜索加时间词**

```python
# 沙漏结果
"2026-06-23 02:43:01" → "找出你自己不停失忆..."

# 向量关键词优化
"失忆 compaction" → "失忆 compaction 2026-06-23 上下文溢出"
```

### 规则 2：同义词扩展

**沙漏找到关键词 → 向量搜索加同义词**

```python
# 沙漏关键词
"cron 失忆"

# 向量同义词扩展
"cron 失忆 sessionTarget session.scope 配置错误"
```

### 规则 3：专门文档词

**向量搜索优先找专门文档**

```python
# 向量关键词模板
"{问题} 根因 修复方案 safe-rules 守则 铁律"
```

## 六、执行纪律

### 铁律 1：三步必须顺序执行

- ❌ 不允许直接向量搜索（漏掉用户原话）
- ❌ 不允许跳过沙漏（漏掉时间点）
- ✅ 先沙漏 → 后向量 → 再文件

### 铁律 2：关键词必须优化

- ❌ 不允许向量搜索用相同关键词
- ✅ 根据沙漏结果优化向量关键词

### 铁律 3：结果必须整合

- ❌ 不允许只输出一种搜索结果
- ✅ 整合三种搜索结果，输出完整信息

## 七、搜索工具对比（实测结论）

### 对比维度

| 维度 | 沙漏搜索 | 向量搜索 | 胜者 |
|------|---------|---------|------|
| **速度** | ⭐⭐⭐⭐⭐ 毫秒级 | ⭐⭐⭐⭐ ~1秒 | 沙漏 |
| **时间跨度** | 2026-06-15 ~ 今 | 2026-05-25 ~ 今 | 向量（+20天） |
| **精度** | ⭐⭐⭐ 关键词匹配 | ⭐⭐⭐⭐ 语义理解 | 向量 |
| **文档覆盖** | ⭐⭐⭐ 对话记录 | ⭐⭐⭐⭐⭐ 所有 MD 文件 | 向量 |
| **找问题根因** | ⭐⭐⭐ 部分找到 | ⭐⭐⭐⭐⭐ 完整分析 | 向量 |
| **找专门文档** | ⭐⭐ 很少 | ⭐⭐⭐⭐⭐ 专门文档优先 | 向量 |

### 数据统计

- **沙漏系统**：1188 条，时间范围 2026-06-15 ~ 今
- **向量数据库**：718 条，时间范围 2026-05-25 ~ 今
- **消化历史**：42 条，时间范围 2026-06-26 ~ 今
- **轮感归档**：50+ 个 MD 文件，时间范围 2026-05-23 ~ 今
